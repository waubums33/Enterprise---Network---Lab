# Enterprise-Network-Lab
Cisco Paket Tracer Lab using OSPF, NAT and ACL.

This project demonstrates a Cisco Packet Tracer enterprise network simulation.

## Features
- OSPF Dynamic Routing
- NAT Overload (PAT)
- ACL Filtering
- Multi-router topology
- Network troubleshooting

## Topology
Three routers connected using serial interfaces with two LAN networks and one server network.

## Tools
- Cisco Packet Tracer
- Cisco IOS CLI

## Purpose
This lab was created to improve networking fundamentals for CCNA and cybersecurity learning.
